# 🎮 FNF Psych Engine - Android Port

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)
[![Build Android APK](https://github.com/klornothiz-ai/FNF-PsychEngine-Android/actions/workflows/build-android.yml/badge.svg)](https://github.com/klornothiz-ai/FNF-PsychEngine-Android/actions/workflows/build-android.yml)

**Psych Engine** ported to **Android** with full Haxe support via **hxcpp + Android NDK**.

## ⚡ Quick Start

```bash
git clone https://github.com/klornothiz-ai/FNF-PsychEngine-Android.git
cd FNF-PsychEngine-Android
./quick_build.sh
```

## 📱 Features

- 🕹️ Touch Controls - D-Pad with multi-touch
- 🎯 Hitbox System - Arrows + Full screen
- 💾 .PsychEngine Storage
- 🎮 Lua Support
- ⚙️ Mobile Options Menu
- 🔄 GitHub Actions CI/CD

## 📦 Requirements

Haxe 4.2.5 | Android NDK r21e | API 34 | JDK 11+
